Campus Courier Clash

Two couriers. One campus. Three minutes to own the last mile.

Open the game →

Start the server

Install Node.js 20 or later. Open a terminal in the directory containing game_server.js and package.json, then run:

npm install
node game_server.js

Browse to http://localhost:8000. This is one Node.js server; there is no build step, database installation, or second process. Stop it with Ctrl+C. If port 8000 is occupied, stop the other process using that port first. Assets are local, so no external asset service is needed.

Test with two players

  1. In a normal browser window, register a new account and sign in.
  2. In a private window or a different browser, register and sign in with a second account. Tabs in one browser profile share a login cookie.
  3. The first player selects Start a new shift and shares the five-character code. The second enters it under Join a friend or selects the room under Open Shifts.
  4. Both players select Ready for delivery. A synchronized three-second countdown starts the match.

On separate computers on the same network, both players can visit the server computer's local network address on port 8000. Keep the server running on that computer.

Rules and controls

Control / elementBehavior
WASD / arrow keysMove. Diagonal movement is normalized. Walls and buildings block movement.
SpaceDash in your current or last-facing direction. Three-second cooldown. Hitting the opponent briefly stuns them and spills one carried parcel.
Gold parcelsWalk over them to collect. Carry at most three. Collected parcels respawn around the shared quad.
Your colored deskWalk into it to deposit your bag automatically. One point per parcel during normal play. The other player's desk cannot deposit your bag.
Campus robotsMove along patrol routes. Contact briefly stuns you and drops one carried parcel. A short immunity period prevents repeated immediate hits.
Green speed power-upsFive seconds of faster movement. Power-ups respawn after twelve seconds.
CToggle cheat mode on/off. Enabled: faster movement, immunity to robots and dash hits, and 12 points per delivered parcel. Deliver one parcel for a quick win. Disabled: normal abilities and future scoring return.
Sound buttonToggle the five local HTML audio effects. The preference is remembered in the browser.

The first player to 12 points wins. Otherwise the match ends after three minutes; the higher score wins and equal scores draw. Simultaneous winning deliveries also draw. On small screens, on-screen direction, dash, and cheat buttons support mouse or touch.

Results and rankings

Results show final score, parcels collected/delivered/dropped, successful dash hits, and robot collisions for each player. The persistent leaderboard sorts by total wins, then total parcels delivered. If those are equal, username provides a stable display order.

Both players can request a rematch, or return to dispatch. A rematch resets the scores, timer, bag, robot positions, power-ups, and cheat status. A match in which either player ever enabled cheating is marked as a practice shift; it shows complete results but does not update cumulative rankings.

Accounts, sessions, and disconnections

data/users.json stores accounts and cumulative results. The delivered ZIP contains an empty database. Passwords are salted and hashed using Node's built-in scrypt. Sessions use an HTTP-only cookie, last up to 24 hours, and survive a page refresh. Restarting the server clears in-memory sessions and rooms; sign in again afterward. Each account supports one active game connection.

Multiple two-player rooms can run independently. Refreshing or briefly losing connection holds your seat for 15 seconds and restores the match. Leaving an active shift forfeits to the connected opponent; leaving during the countdown cancels it without changing rankings. If both players disconnect, an expired seat cancels the match.
